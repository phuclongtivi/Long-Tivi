# TV / longTV Spec

- TV app name: `longTV`.
- TV app logo: `long.live` + `TV`, keeping the mascot in the logo.
- Primary connection: TV shows QR code, phone scans to remote/control.
- Phone remains the logged-in control device.
- TV is display/player only.
- Fallback: `1986.tv/connect` Web TV Mode.
- Default output quality: 720p.
- Optional quality: 1080p, not default.
- Recommended streaming: HLS adaptive ladder 360p / 480p / 720p.
- 1200p and 4K remain later roadmap items.

## User Flow

1. User taps `Kết nối Tivi` in LIVE or Menu.
2. User chooses `Cài app longTV`, `Quét mã trên Tivi`, or `Mở bằng trình duyệt Tivi`.
3. TV shows QR code or six-character code.
4. Phone scans/enters code.
5. Phone controls content; TV displays video/live/event/store content.
