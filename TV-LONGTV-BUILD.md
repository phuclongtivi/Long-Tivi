# longTV Android TV App

Status: Android TV source scaffold added.

## Included

- Source path: `android-tv/longTV/`
- App name: `longTV`
- Package id: `live.longtv.app`
- Launch target: Android TV / Google TV via `LEANBACK_LAUNCHER`
- Default URL: `https://1986.tv/connect?device=longTV&quality=720p`
- Default quality: 720p

## Logo Direction

Final store asset should use `long.live` + `TV`, while keeping the mascot inside the logo. The current Android TV scaffold includes a placeholder vector icon so the project can exist in source form. Replace it with final generated mascot logo assets before store submission.

## Build Notes

This folder is source only. To create a TV `.aab`, open it in Android Studio with Android SDK installed, configure release signing, then build a release bundle.
