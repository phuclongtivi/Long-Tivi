# AI Agent Spec

## Personal AI Level 2

- Agent works inside 1986 first.
- User can edit name, tone, proactive level, avatar/mascot direction, memory, and permissions.
- Skills: Live, Chat, superBUY, Notifications, TV/AR.
- Permission default: Level 2, prepare drafts and ask user to confirm.
- Action log required for important actions.

## AI Router

- ChatGPT: agent orchestration, conversation, planning, contextual reasoning.
- Gemini: multimodal/image/video/live context when needed.
- DeepSeek: text, reasoning, batch/low-cost tasks when appropriate.

## Guardrails

- User controls memory.
- User controls action permissions.
- AI does not operate live/items/stores without a clear UX permission.
