# 3 gian hàng sticker + kho Boss

- Kho Boss: 1.000.000 cái **mỗi loại** sticker (cấp 1 + 2 + 3) — `seedBossVault()`.
- Shop: `Sticker Level 1` / `Sticker Level 2` / `Sticker Level 3`.
- SKU: 1 mặt hàng / shop. Đơn **cố định 5 cái**.
- Giá gói = 5 × điểm sticker × 1.000đ  
  L1 = 5.000đ · L2 = 10.000đ · L3 = 25.000đ.
- Ảnh đại diện: carousel luân phiên ~1.1s/ảnh.
- Vào xem: lưới từng sticker + PDP kiểu Shopee (`ShopeeProductSheet` dùng cho mọi SKU superBUY).
- Thanh toán mặc định: chuyển khoản QR (`/pay/boss-qr.png`).
