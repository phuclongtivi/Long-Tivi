# Boss Menu Spec

## Login

- Boss uses a separate login route from normal users.
- Boss login requires Google Authenticator/2FA direction.
- Session timeout, login history, and unusual-login alerts are required before production.

## Boss Menu

- App dashboard.
- LIVE operations.
- Home/event notice operations.
- superBUY/store/inventory/ticker operations.
- User management.
- Moderation/report/block operations.
- Boss AI and AI user policy.
- TV/longTV and AR/VR/MR entries.
- App Store/Google Play/TV release tracking.

## Boss AI

- Boss AI can propose and apply global AI-user policy after Boss confirmation.
- Boss AI can prioritize Live, commerce, moderation, event reminders, and safety.
- Boss AI must log every directive and policy change.
- Boss AI should not read private user memory without explicit permission, reason, and logs.
